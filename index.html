The website only saves the text. Trained coders code students' messages and reasons after data collection. The website does not code anything itself.

One week later

Students take an ungraded quiz in class through a lockdown browser. There are no cards and no AI. All items are new, and none repeats a practice problem. Each item has a 0 to 100 confidence rating.

OutcomeSample item
Memory ([5] items, one per key concept)What does Levene's test check?
When do you read "Equal variances not assumed"?
What does a p value mean?
What p value makes a difference statistically significant?
What do you conclude when p is .05 or higher?
Application ([5] items)A new SPSS output and scenario: which row do you read, what is the p value, and what do you conclude?
Calibration = confidence − accuracy, averaged across items
Example: 90% confident on an item answered wrong: 90 − 0 = +90 (overconfident)
Example: 40% confident on an item answered right: 40 − 100 = −60 (underconfident)

Calibration uses the quiz and not the class task, because task accuracy can reflect help from the AI.

Prototype only. The sample output is computed from the means and SDs shown, except Levene's F and p, which are example values. The tutor replies here are scripted around four steps. For the pilot, API calls will make the tutor adaptive, with the same rules: give feedback on every reply, never repeat a question word for word, and never state the final answer. Study data will be stored on secure UM systems, and AI will run on a local LLM or a UM-approved setup. No data leaves this page.
